# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/aa217c9b-baff-4d96-b127-9be465fd5c6f

## Iniciar con un clic en Windows

1. Asegúrate de tener Node.js instalado.
2. Abre `Iniciar Reto Global.bat` con doble clic.

El lanzador instala las dependencias la primera vez, inicia el servidor local en segundo plano y abre Reto Global en una ventana independiente de Edge o Chrome cuando alguno está instalado. El botón `INICIAR JUEGO` de la pantalla inicial comienza la partida.

Al cerrar la ventana del juego, el servidor local puede seguir activo en segundo plano. Para detenerlo, abre `Detener Reto Global.bat` con doble clic.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
